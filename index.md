# Rclone-GoogleDrive

Rclone-GoogleDrive is a personal desktop configuration of
the open-source rclone file transfer tool, maintained by JacksonNi.

It is used only by its owner to upload, download, list, and
organize files between the owner's computer and Google Drive.

This application is not offered as a public service.

## Privacy Policy

Last updated: October 30, 2026

This configuration uses Google OAuth to access the owner's
Google Drive with the permissions granted during authorization.

Google Drive file contents and metadata are accessed only
to perform operations requested by the owner.

This project does not operate a separate server to collect
Google user data. OAuth credentials and tokens are stored
in the owner's local rclone configuration.

Google user data is not sold, used for advertising, or
intentionally shared with third parties.

The owner can revoke this application's access at any time
through Google Account security settings and delete the
local rclone configuration.

## Terms of Use

This configuration is for the owner's personal use only.
The owner controls all file operations and permissions.
